# SharePoint UI

A small React component library for SharePoint Framework. It starts with a SharePoint-derived theme engine and three native HTML components: Button, Input, and Card.

```sh
npm install
npm run build:library
npm run build:spfx
npm run build:docs
```

The package publishing workflow remains tag-triggered (`v*`). Publishing to npm is a maintainer action and is not part of local development.

See [the docs site](https://vystartasv.github.io/sharepoint-ui/) and [package README](packages/sharepoint-ui/README.md) for usage.
