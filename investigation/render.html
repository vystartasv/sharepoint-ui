INITIAL DISCOVERY · SPFx 1.24

A SharePoint native UI system, built for speed.

Early evidence points to a token-first library with a React 18 adapter for SPFx and a path to Web Components. Keep host awareness, accessible behavior, and small feature imports at the center.

The opportunity

SharePoint is the runtime, not just a target

Sections, theme variants, tenant palettes, and SharePoint loading constraints deserve first-class APIs. The system should feel familiar like Fluent while making the host integration disappear for the app author.

SP theme→semantic tokens→React / Web Components
Early recommendation

React first; keep the core portable

SPFx 1.24 officially pins React 18.3.1. A shared CSS variable token contract and behavioral primitives leave room for custom elements once a real non-React use case is proven.
