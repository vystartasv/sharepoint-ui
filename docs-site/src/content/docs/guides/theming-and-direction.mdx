title: Theme, typography, and direction
description: Inherit SharePoint colors, add a design theme, and let locale determine LTR or RTL layout.
---

## Start with the tenant theme

SharePoint UI derives semantic colors from the host theme and section surface. Use a design theme only for product choices the tenant theme does not express, such as a font, spacing rhythm, or an explicit brand accent.

```tsx
import {
  SharePointUIProvider,
  composeSharePointUIDesignThemes,
  type SharePointUIDesignTheme,
} from "@vilius/sharepoint-ui/react";

const productTheme = {
  typography: { fontFamily: '"Aptos", sans-serif' },
  spacing: { fieldGap: "1rem", sectionGap: "1.5rem" },
  shape: { controlRadius: "0.5rem" },
} satisfies SharePointUIDesignTheme;

<SharePointUIProvider theme={composeSharePointUIDesignThemes(productTheme)}>
  {children}
</SharePointUIProvider>
```

Theme packs compose left to right; later packs override earlier values. Host-derived SharePoint values remain the defaults. Provider token values can be used for a final app-level override, and `customProperties` can carry app-specific CSS variables.

## Use the current UI culture for RTL

Set the provider `lang` from the SPFx page culture. Arabic and other RTL locales resolve to right-to-left direction, and components use logical start/end placement. If the host gives a language value without direction information, set `dir="rtl"` on the owning app region. Keep the content's actual `lang` accurate for assistive technology.

```tsx
<SharePointUIProvider lang={this.context.pageContext.cultureInfo.currentUICultureName}>
  <RequestWorkspace />
</SharePointUIProvider>
```

Avoid setting `dir` independently on individual controls; a single inherited direction keeps menus, drawers, navigation, and text aligned.

## Tune a local surface

For a one-off region, set a semantic custom property on its wrapper instead of overriding component internals:

```css
.approval-panel {
  --spui-ui-accent: #1769aa;
  --spui-font-family: "Aptos", sans-serif;
}
```

Use the [token reference](/sharepoint-ui-docs/components/text/) and the theme sections in the [package README](https://github.com/vystartasv/sharepoint-ui/blob/main/packages/sharepoint-ui/README.md) for available semantic roles and SharePoint palette mappings.
