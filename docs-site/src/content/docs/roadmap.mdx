description: What we plan to improve next.
---

## 1. Make the editor work well on phones

Text selection, formatting, and color controls should feel straightforward and stay out of the way.

## 2. Make the docs work on every screen

Examples should be easy to find, view, and try on phones, tablets, and desktops.

## 3. Simplify the project

Review areas that add complexity. Keep them only when their benefit is clear; explain the tradeoff before adding more.

## 4. Polish the library

Make components feel consistent, follow SharePoint themes and languages, and cover the features people expect.

## 5. Prepare the next release

Once the main experience is ready, prepare the package for release. Vilius will publish it to npm.

No release dates are set yet.
