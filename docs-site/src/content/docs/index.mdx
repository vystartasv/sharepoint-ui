## Install

In an SPFx project that uses React 18.3.1, install the package and import its stylesheet once:

```sh
npm install @spfx-fast/sharepoint-ui
```

```tsx
import { Button, Field, Input, SharePointThemeProvider } from "@spfx-fast/sharepoint-ui/react";
import "@spfx-fast/sharepoint-ui/styles.css";

function RequestForm() {
  return <SharePointThemeProvider>
    <form>
      <Field id="title" label="Title" required>
        <Input name="title" required />
      </Field>
      <Button type="submit">Save</Button>
    </form>
  </SharePointThemeProvider>;
}
```

React is supplied by the SPFx host. The library renders controls and reports interaction; your web part handles SharePoint requests, permissions, validation, and persistence.
