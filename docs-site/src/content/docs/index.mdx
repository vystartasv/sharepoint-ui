## Start with the host, keep your own stack

SharePoint UI maps SharePoint and Fluent theme values into reusable controls. Use the React adapter in SPFx, or register custom elements directly when React is not part of the page.

```sh
npm install @vilius/sharepoint-ui
```

The package keeps React optional for custom-element consumers and supports SPFx 1.24 with React 18.

## Compose an SPFx view

```tsx
import { Button, SharePointUIProvider, ViewCard } from "@vilius/sharepoint-ui/react";

<SharePointUIProvider lang={pageContext.cultureInfo.currentUICultureName}>
  <ViewCard kind="list-item" title={item.Title} subtitle={item.Modified} description={item.Status}>
    <Button slot="action" appearance="primary">Open item</Button>
  </ViewCard>
</SharePointUIProvider>
```

The `lang` value controls localization and text direction. Components inherit the site theme and remain in the SharePoint section that owns them.
