# Build SharePoint forms agents can operate

SharePoint UI is a compact set of native HTML controls with a theme engine that reads SharePoint's active palette. React 18.3.1 stays external and is supplied by the SPFx host.

Start with the smallest component that does the task. Keep labels visible, let the browser handle standard interactions, and use semantic roles and names so people and browser agents can find the same control.

## Design rules

- One `Button` for actions. Use `Checkbox` for independent choices, `RadioGroup` for one-of-many, and `Switch` only for immediate on/off settings.
- Prefer native controls: `Input`, `Select`, `TextArea`, `DatePicker`, and `FileUpload` retain browser keyboard and form behavior.
- Use `Field` for a visible label, hint, and validation message.
- Use `data-agent-id` only when a page has duplicate accessible names. Agents should prefer role and label locators.
- The host owns SharePoint reads, writes, permissions, and upload transport.
