## A component system shaped for SharePoint

SharePoint UI gives SPFx developers and coding agents a searchable set of controls, compound components, and reusable SharePoint views. Components inherit SharePoint and Fluent theme values. Use the React adapter in SPFx, or register custom elements directly from plain JavaScript and other frameworks.

```sh
npm install @spfx-fast/sharepoint-ui
```

The package targets SPFx 1.24 and React 18. React is an optional peer dependency; custom-element consumers can import only the definitions they need.

## Compose an SPFx view

```tsx
import { Button, SharePointUIProvider, ViewCard } from "@spfx-fast/sharepoint-ui/react";

<SharePointUIProvider lang={pageContext.cultureInfo.currentUICultureName}>
  <ViewCard kind="list-item" title={item.Title} subtitle={item.Modified} description={item.Status}>
    <Button slot="action" appearance="primary">Open item</Button>
  </ViewCard>
</SharePointUIProvider>
```

The `lang` value controls localization and direction. Components inherit the site theme and stay within the SharePoint section that owns them. Keep SharePoint data access and persistence in the web part; the UI components expose the interaction and value changes.
