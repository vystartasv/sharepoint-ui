---
title: SharePoint UI
description: Small themeable React components for SharePoint Framework.
---

SharePoint UI is a compact React component library designed for SharePoint pages. It uses native HTML controls, inherits SharePoint theme colors, and keeps React as a host supplied peer dependency.

## Install

```sh
npm install @spfx-fast/sharepoint-ui
```

## Components

The initial component set is Button, Input, and Card. See the package README for usage and theming details.
