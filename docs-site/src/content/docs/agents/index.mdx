## Start here

[Open the quickstart](/sharepoint-ui/agents/QUICKSTART.md) for install, shared composition rules, and copy-ready React and custom-element examples. The human [component conventions guide](/sharepoint-ui/guides/component-patterns/) explains what transfers across controls. For a focused task, give the agent the relevant component page and its linked JSON slice.

For a full SPFx 1.24 Copilot solution, use the [framework-free CLI template](https://github.com/vystartasv/sharepoint-ui/tree/main/templates/spfx-fast-copilot-access-review) or start from its [buildable example](https://github.com/vystartasv/sharepoint-ui/tree/main/examples/spfx124-copilot-ux).

## Use a component slice

For a Button task, send [`button.json`](/sharepoint-ui/agents/components/button/button.json). Component pages link directly to their JSON slice. For all controls in a module, use a module slice such as [`input.json`](/sharepoint-ui/agents/modules/input.json). Add the agent guide only when the task spans app-level conventions; use the full manifest for cross-family composition.

Rich text editing is part of the normal component API and has a dedicated [`Rich Text Editor` JSON slice](/sharepoint-ui/agents/components/rich-text-editor/rich-text-editor.json), a [live human-readable component page](/sharepoint-ui/components/rich-text-editor/rich-text-editor/), and a [SharePoint persistence guide](/sharepoint-ui/guides/rich-text-editor/).

## Give an agent a focused request

```text
Build the requested SharePoint view with @spfx-fast/sharepoint-ui.
Use the attached AGENTS.md and the JSON slice for the components you need.
Keep SharePoint data loading and persistence in the web part. Use documented
slots and callbacks, inherit the current theme, and set lang so RTL follows
the content locale. Do not import the full element registry for a small view.
```

The short machine index at [`/llms.txt`](/sharepoint-ui/llms.txt) links to the quickstart, full catalog, and every module slice. Human docs explain behavior; package TypeScript declarations define the API.
