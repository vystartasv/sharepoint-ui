## Use a field

```tsx
import { Button, Field, Input, SharePointThemeProvider } from "@spfx-fast/sharepoint-ui/react";
import "@spfx-fast/sharepoint-ui/styles.css";

function RequestForm() {
  return <SharePointThemeProvider>
    <Field id="request-title" label="Request title" required>
      <Input name="title" required />
    </Field>
    <Button type="submit">Save request</Button>
  </SharePointThemeProvider>;
}
```

## Compose a list workflow

Use `FilterBar` for labelled filters, `ListView` for results, and `ViewSwitcher` only when users can choose a layout. Use `FileDropzone` to collect files and `AttachmentList` to display host-managed upload status. These components do not call SharePoint.

The full list is available in the package's [`components.json`](https://github.com/vystartasv/sharepoint-ui/blob/main/packages/sharepoint-ui/components.json).
