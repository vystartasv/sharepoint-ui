# Components

Explore {availableComponents.length} components. Open any item to see the real React component, interact with its example, and adjust the shared theme controls.

## Choose by task

- Label and validate one value: `Field` with `Input`, `Select`, or `TextArea`.
- Choose one or more values: `RadioGroup` or `Select` for one choice; `TagPicker` for several.
- Search and page through records: `ListView` with `FilterBar`; use `DataGrid` when rows need sorting or selection.
- Select files and show upload status: `FileDropzone` with `AttachmentList`.
- Find a person or related list item: `PersonPicker` or `LookupPicker` with options loaded by the host app.
- Submit a form: use a native `<form>` and `Button`.

The library renders controls and reports events. The host app loads and saves SharePoint data, checks permissions, validates values, and uploads files.
