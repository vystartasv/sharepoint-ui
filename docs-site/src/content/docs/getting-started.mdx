---

## Install

```sh
npm install @spfx-fast/sharepoint-ui
```

React consumers can import the adapter. Framework-neutral consumers can import only the custom-element factory they need.

## React in SPFx

```tsx
import { SharePointUIProvider, Button, TextField } from "@spfx-fast/sharepoint-ui/react";

export function RequestForm({ locale }: { locale: string }) {
  return (
    <SharePointUIProvider lang={locale}>
      <TextField label="Request title" name="title" required />
      <Button appearance="primary" type="submit">Create request</Button>
    </SharePointUIProvider>
  );
}

// In the SPFx web part's render method:
const locale = this.context.pageContext.cultureInfo.currentUICultureName;
return <RequestForm locale={locale} />;
```

Use the SPFx locale instead of hard-coding direction. Arabic and other right-to-left locales receive RTL layout from the language value. Add `dir` explicitly if the culture identifier does not follow the browser's locale direction mapping.

## Custom elements

```ts
import { defineButton } from "@spfx-fast/sharepoint-ui/elements/button";

defineButton();
```

```html
<spui-button appearance="primary">Create request</spui-button>
```

For component-specific factories, slots, events, and styling hooks, use the [component catalog](/sharepoint-ui/catalog/).
