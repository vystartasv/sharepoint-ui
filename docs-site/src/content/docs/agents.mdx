# Agents

Use the accessibility tree as the interaction contract. Start with a native role and accessible name; use `data-agent-id` only when names are duplicated.

```ts
const title = page.getByRole("textbox", { name: "Work item title" });
await title.fill("Update the team site");
await page.getByRole("button", { name: "Save work item" }).click();
await expect(page.getByRole("status")).toContainText("Saved");
```

Check the [component guide](/sharepoint-ui/components/) before choosing a control. The package's `components.json` is the machine-readable inventory. The package does not read or save SharePoint data; use the host workflow and verify its visible result.

For agent retrieval, see the [plain Markdown interaction contract](/sharepoint-ui/agents/AGENTS.md).
